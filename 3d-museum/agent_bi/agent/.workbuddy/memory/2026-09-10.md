# 2026-09-10 博物馆 Agent：语音体验优化

## 语音分句断句引擎（static/index.html 重写）
- 原问题：整段文本塞进单个 SpeechSynthesisUtterance，换行被压成空格，TTS 一口气读完不断句，听着累
- 新方案 `splitIntoUnits()`：先按句末标点（。！？!?…；;）切分，超过 42 字的长句再按逗号/顿号切成 ≤22 字小分句；每句一个独立 utterance，句间停顿 380ms、分句间 180ms，由 `playNextUnit()` 顺序播放
- 朗读前清除 emoji（\u{1F000}-\u{1FAFF} 等），避免 TTS 读出怪声
- 用 `SPEAK_SESSION` 递增令牌防旧队列在新朗读/stopSpeaking 后残留播放

## 人物音色档案
- `CHAR_VOICE_PROFILES`：秦始皇(male, pitch 0.72)、武则天(female, 0.92)、李白(male, 1.0)、苏轼(male, 0.86)、李清照(female, 1.2)
- 男声优先匹配 Kangkang/Yunyang/Yunxi/Yunjian，女声匹配 Xiaoxiao/Yaoyao/Huihui/Tingting；系统无中文男声时退回女声但保留低 pitch 区分
- 未建档人物（用户新增的历史人物）：按名字哈希生成稳定音色（同一人物每次一致）
- 问答页历史人物模式：speak() 自动套用当前角色音色
- 小剧场 speakTheater()：逐句朗读，A/B 角色各用各的音色，旁白用知性女声；朗读时高亮当前台词（.tl-line.speaking-line）并平滑滚动；若两角色被分到同一系统声音，自动播报说话人名字区分

## 音色分配增强（2026-09-11 补充）
- `classifyVoices()`：把系统中文声音按命名规律分成男声池/女声池（康康/云扬/云希/云健→男；晓晓/瑶瑶/慧慧/晓伊→女），缓存于 VOICE_POOL，onvoiceschanged 时置空重建
- 人物档案增加 `pref` 字段：每个历史人物偏好贴合形象的系统声音（秦始皇→云健浑厚、李白→康康明亮、武则天→瑶瑶、李清照→晓伊清亮）
- `pickVoiceFor(p, usedNames)` 四级分配：①偏好声音且未被占用 → ②同性别池中未被占用的声音（实现同性别人物各用不同声音）→ ③该性别任意声音（靠 pitch/rate 区分）→ ④兜底声音 + pitch 拉性别感（男≤0.7 / 女≥1.1）
- 小剧场 speakTheater()：A、B、旁白依次分配声音（used Set 去重）；两角色被迫共用同一声音时自动拉大 pitch 差 ±0.28 并播报说话人名字
- 未建档人物哈希档案同步接入声音池

## 四项语音微调（2026-09-11 二次）
- 问答页角色朗读补上「同声音补偿」：角色与讲解员被分到同一系统声音时，男性角色 pitch 压到讲解员 -0.28 以下，女性角色按相对方向 ±0.2，语速同步微调（原先只有小剧场有此补偿，导致用户觉得问答页音色没变）
- 李清照从「清亮少女」(pitch 1.25/1.02) 改为「成熟才女」(pitch 1.02, rate 0.96, 偏好慧慧/瑶瑶)
- 逗号顿号停顿 180→130ms、分号 260→200ms（浏览器 utterance 间本身有空隙，叠加后原来偏拖沓）；句末 380ms 不变
- generateTheater() 开头调用 stopSpeaking()：生成新剧本自动停止旧朗读

## 注意
- Web Speech API 的 voice 列表在 Chrome 需异步加载（onvoiceschanged），首条消息朗读可能拿不到 voiceObj → 自然降级为默认声音
- switchTab 离开小剧场时重置 window.__theater_kids=false 并 stopSpeaking()，避免影响问答页语速
