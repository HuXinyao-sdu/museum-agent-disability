### 核心技术点：stdlib 反向代理透传 SSE
- **关键坑**：http.client 的 resp.read(65536) 会阻塞直到读满 65536 字节或 EOF，SSE 小事件永远卡住不转发
- **修复**：改用 resp.read1(65536)——读到多少转发多少，最多一次底层 read 调用
- 代理需支持：POST JSON、GET SSE 流、HEAD（视频就绪探测）、Range（视频拖进度条）
- 逐跳头（Connection/Transfer-Encoding 等）不透传；SSE 不透传 Content-Length
