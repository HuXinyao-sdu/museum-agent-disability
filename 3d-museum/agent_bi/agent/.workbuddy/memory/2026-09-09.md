## 博物馆智能问答 Agent 应用（museum-agent）
- 位置：`D:\3th\人工智能应用实践\agent\museum-agent\`
- 架构：Python 标准库 HTTP 服务器（server.py，零第三方依赖，端口 8300）+ 原生单页前端（static/index.html）+ JSON 知识库（data/knowledge.json）
- 功能：网页智能问答（中文一元/二元字符特征 + 标题/关键词/内容三级加权检索，含文物列表意图、置信度、兜底引导）；网页端知识库自助管理（增删改查/搜索/JSON 导入导出）
- 初始种子：8 条博物馆馆务示例数据（简介/开放时间/门票/交通/须知/便民服务/讲解/征集），文物条目留空由用户自行添加
- 调参经验：匹配阈值 0.6、关键词完整命中加权 +1.5 效果较好；未命中关键词时靠补充同义词（如"怎么去/如何去/去博物馆"）提高召回
- 启动：`python server.py` → http://localhost:8300；接口文档见项目 README.md
